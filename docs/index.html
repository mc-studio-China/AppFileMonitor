它能做什么

文件变化监控

选定一个应用，自动对比基线，列出它新增、删除、修改的每一个文件。

免 Root 读写

通过 Shizuku 直接读写 Android/data、Android/media 与共享 Download。

文件管理器

浏览、复制、移动、重命名、编辑文本，任意应用的数据目录都能进。

后台自动扫描

WorkManager 每 15 分钟静默扫描一次，异常变动不容易漏掉。

三种启动方式

  1. 无线调试（免电脑）：开发者选项开启「无线调试」→ Shizuku 内点配对 → 输入 6 位配对码 → 启动。
  2. Root：已 Root 机型在 Shizuku 中选择「通过 Root 启动」，随后在本应用授权并检测 Root。
  3. USB / ADB：连接电脑执行 adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh

界面语言

默认跟随系统，也可以在「设置 → 界面语言」里手动切换。
